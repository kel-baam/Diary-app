## 🚀 Installation

**1. Clone the repository**

```bash
git clone <repository-url>
```

**2. Install dependencies**

```bash
npm install
```

**3. Start the application**

```bash
npx expo start
```

**4. Run it on your device**

Scan the QR code with the **Expo Go** app (📷 iOS Camera or the Expo Go scanner on Android) to launch it on your mobile device.

> 💡 Don't have Expo Go? Grab it from the [App Store](https://apps.apple.com/app/expo-go/id982107779) or [Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent).
